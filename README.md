# SimWorld 模拟实验室

DeepSeek Harness 桌面端左侧栏的模拟实验插件。内置校园食堂和小型市场两个场景，支持自定义方案数量、选择基准、批量生成 Agent、逐个编辑人格和初始状态，以及查看方案指标和事件记录。

## 开发

```powershell
npm ci
npm test
npm run build
npm pack
```

在目标 profile 中用 `dsh plugin --profile desktop add file:<包的绝对路径>` 安装。重新打开 DSH，从左侧栏进入「模拟实验室」。本版针对 DSH 0.2.1-rc.5 开发。

## 模拟

方案共享初始 Agent。市场的到访随机数按种子重放，食堂使用固定到达时刻。食堂的平均等待时间仅统计已完成服务的人，未完成指标包含已到达且仍在等待或服务中的人。市场利润按实际成交单价减单位成本计算。

`src/core.mjs` 提供独立的 `runComparison(config)`。DSH 插件通过该函数运行实验。未来其他调用方可以复用相同的 JSON 输入输出。本版用规则驱动 Agent，实验结果取决于示例参数，页面草稿保留在当前面板内。

## 自定义世界（0.2.0）

新版面板沿用 DSH 主题，按「世界 → 人物 → 方案 → 结果」组织操作。现有食堂和市场可从世界列表打开，继续使用原来的方案和参与者配置。

1. 选择「校园应急疏散」直接运行示例，或选择「自定义世界」从空白草稿搭建。可设置地点、双向通道、世界状态、自定义指标和触发规则。
2. 在「人物」编辑角色模板，批量加入参与者，或覆盖个人起点、速度、反应延迟、已知出口和策略。AI 可以在「世界」生成草稿；确认后在表单继续编辑。
3. 在「方案」设置分叉时间、种子、基准和干预，运行后查看配对结果与事件。导出的 JSON 含实验配置；完整实验导出另外包含引擎版本、每次运行结果、事件及截断计数。两种文件均可重新导入配置。

自定义世界运行器由包的 `./world` 导出 `validateExperiment(config)` 和 `runExperiment(config)`。后者接收 `{world, forkAt, baseline, seeds, plans}`，在各随机种子的分叉前共享状态，随后独立执行各方案。全局规则先更新环境，再发通知，最后执行角色规则。同一秒的通道竞争按等待时间、种子生成的顺序和人物标识处理。经典模板继续使用原 `./core` 接口。

疏散模板使用合成地点和人物，只用于比较模拟假设。规则和人物策略由引擎执行，模型只生成可编辑的配置草稿。
